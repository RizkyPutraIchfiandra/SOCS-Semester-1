## Isi

| Folder | File | Fokus |
| --- | --- | --- |
| `Arithmetic & Operations` | 31 | operator aritmetika, ekspresi, dan logika dasar |
| `Input & Output` | 19 | `printf`, `scanf`, dan format input/output |

Setiap file adalah program mandiri dengan `int main()`, tanpa header atau library buatan sendiri. Nama file mengikuti nomor soal (`ProblemA.c` sampai `ProblemAD.c`, `InputOutputA.c` sampai `InputOutputS.c`).

## Menjalankan

```bash
gcc "Input & Output/InputOutputA.c" -o latihan
./latihan
```

Di Windows, hasil kompilasi menjadi `latihan.exe` dan dijalankan dengan `.\latihan.exe`.

## Catatan

- Tidak ada build system atau dependensi eksternal.
- Repo ini arsip latihan kuliah, jadi kode ditulis apa adanya sesuai soal, bukan sebagai library.
